# FGK Corp

[Витрина](https://georgy-hook.github.io/fgk-corp/) · [Студия каталога](https://georgy-hook.github.io/fgk-corp/admin/) · [Статус публикаций](https://github.com/Georgy-hook/fgk-corp/actions/workflows/pages.yml)

Каталог моделей для печати. Первый экспонат — [Буран БТС-001 с ВДНХ](https://georgy-hook.github.io/fgk-corp/?model=buran-vdnh), масштаб 1:144. Витрина показывает изображения и загружает 3D только по кнопке «Вращать в 3D». Посетитель выбирает окрас и оставляет заявку без аккаунта и предоплаты.

## Добавить или изменить товар в студии

1. В `/admin/` найдите карточку по названию или нажмите **«Новая модель»**. Для подготовки не нужен ключ. Заполните название, категорию и описание: адрес предложится автоматически. Перетащите обложку и файлы, при желании добавьте ракурсы, характеристики и окрасы.
2. Для печати подходят отдельные STL или ZIP с файлами STL. Для целой сборки приложите самодостаточный **GLB 2.0**. Если есть только STL, витрина позволяет осматривать детали по отдельности. Архив ZIP сам по себе не является 3D-сценой. Ограничения студии: до 10 МБ на изображение, до 70 МиБ на GLB, STL или ZIP, до 64 файлов для печати и до 128 МиБ новых файлов за одну публикацию. Для больших комплектов используйте импорт из папки.
3. Проверьте предпросмотр и список замечаний. У карточки Бурана собственная сцена и экспозиция: при редактировании их не нужно загружать заново. Черновики и выбранные файлы остаются **только в открытой вкладке**, в том числе после переключения карточки или выхода. Закрытие/перезагрузка их сбрасывает.
4. Нажмите **«Продолжить с GitHub»**. По ссылке в диалоге создайте короткоживущий fine-grained token: владелец `Georgy-hook`, **только** репозиторий `fgk-corp`, разрешение **Contents: Read and write**. Студия не сохраняет ключ. Подключение ничего не публикует — подтвердите кнопкой **«Опубликовать модель»** или **«Опубликовать изменения»**. Карточка и новые файлы записываются одним коммитом без принудительного обновления ветки.
5. Дождитесь успешного завершения GitHub Actions. Ссылка на товар: `https://georgy-hook.github.io/fgk-corp/?model=<slug>`. При конфликте перечитайте карточку из `main` и сверьте правки: студия не перезаписывает чужую версию.

## Импорт из папки через Git

В одной папке разместите обложку `cover.webp` (также JPG/PNG/AVIF), дополнительные фотографии, STL или ZIP и, при необходимости, один GLB со встроенными ресурсами. Из корня репозитория:

```sh
python3 scripts/import-model.py /путь/к/файлам --slug first-kit --name 'Набор деталей' \
  --category 'Техника' --description 'Модель для сборки и печати.' --color 'Серый=#76868f'
```

Если у обложки другое имя, добавьте `--cover имя-файла.jpg`. `--color` можно повторять. Команда проверяет файлы и создаёт `catalog/<slug>/` с `product.json`: ничего не пушит, не заменяет существующий товар и не меняет остальные карточки. Затем закоммитьте эту папку и отправьте в `main`.

Можно составлять `product.json` вручную по образцу `catalog/buran-vdnh/product.json`. `catalog/index.json` задаёт приоритетный порядок, а **остальные папки с `product.json` обнаруживаются автоматически**. Черновые папки для непубличных товаров держите вне `catalog/`. Каталог, изображения и комплекты STL на GitHub Pages публичны. Для GLB первый цвет соответствует исходным материалам; при желании отметьте перекрашиваемые материалы через glTF `extras.fgkPaint: true`.

## Заявки

Форма передаёт модель, окрас и контакт (Telegram, ВКонтакте или email) в Netlify Forms. Имя и комментарий необязательны. Детали заказа и оплату мастерская согласует лично. Заявки и email-уведомления доступны владельцу в [Netlify](https://app.netlify.com/projects/fgk-corp-orders/forms) или по ссылкам раздела **«Заявки»** в студии. Публичный сайт не получает список покупателей или ключ Netlify.

Описание зарегистрированной формы и заголовки CORS находятся в `order-relay/public/`. Если меняется схема полей, обновите форму на существующем Netlify-проекте `fgk-corp-orders`. Для обычного добавления товара этого делать не нужно.

## Локальный просмотр

```sh
python3 scripts/check-catalog.py --output catalog/products.json
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080/` или `/admin/`. После добавления товара через Git снова запустите генерацию `products.json`. Проверка и упаковка на Pages происходят автоматически; производственный почтовый маршрут настроен для origin `https://georgy-hook.github.io`.
