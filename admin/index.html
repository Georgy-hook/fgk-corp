    Доступ к GitHub

    Для записи в Georgy-hook/fgk-corp нужен короткоживущий fine-grained token. Подключение само по себе ничего не публикует.

    1. Создайте ключ на GitHub ↗ со сроком на один день.
    2. В Only select repositories выберите только fgk-corp.
    3. Разрешите только Contents: Read and write. Metadata доступно для чтения автоматически.

    Ключ вводится только в отдельно открытой студии. Открыть студию в отдельной вкладке

    Только в памяти вкладки. Кнопка «Выйти» забывает ключ, но оставляет черновики.

    Изменить почту уведомлений ↗
